# Pet Store API Automation - Regression Suite

## Overview

This repository contains automated tests for the **Pet Store API**. The tests are built using **TypeScript**, **Axios** for making API requests, and **Jest** as the test runner. The goal of this repository is to ensure that the Pet Store API works as expected through automated regression tests.

The automation suite is based on the Swagger documentation for the Pet Store API and includes tests for various endpoints.

## Prerequisites

Before running the tests, make sure you have the following installed:

- **Node.js**
  [Install Node.js](https://nodejs.org/)
- **npm**
  npm is included with Node.js.
- **TypeScript**
  You can install TypeScript globally using npm:
  npm install -g typescript

**Steps to run the script locally**

1. Clone the Repository:
   git clone https://github.com/archana140281/archana_test.git

2. Navigate to Project Directory:
   cd petstore-api-automation

3. Install Dependencies:
   npm install

4. Running Tests Locally:
   To run the tests locally using Jest, simply run the following command:
   npx jest
